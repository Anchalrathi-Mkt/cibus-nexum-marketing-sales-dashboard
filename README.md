# Cibus Nexum – Marketing, Sales & Project Dashboard

An Excel-based portfolio project demonstrating B2B marketing, lead generation, and manufacturing project support for Cibus Nexum.

## Project Features
- **B2B Lead Generation:** Prospect research, CRM tracking, and follow-ups.
- **LinkedIn Marketing:** Content calendar, campaign planning, and performance tracking.
- **Project Management:** Manufacturing outsourcing workflow and milestone tracking.
- **Market Research:** Food industry trends and business opportunities.
- **Dashboard:** Sales, marketing, and project performance KPIs.

## Tools Used
Microsoft Excel, CRM concepts, data analytics, and marketing strategy.

## Objective
To demonstrate how I can support Cibus Nexum in client acquisition, digital marketing, and project coordination during a six-month internship.

*Disclaimer: Independent portfolio project using illustrative data, not an official Cibus Nexum project.*
