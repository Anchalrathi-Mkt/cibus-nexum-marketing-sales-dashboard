Project overview
This Excel workbook demonstrates a proposed approach to supporting marketing, B2B prospecting and food-manufacturing outsourcing projects in a consulting environment. It is designed to make routine work trackable, from initial company research through LinkedIn content planning and project coordination to KPI reporting.
Workbook structure
Worksheet	Purpose
Guide	Explains the sample project and workbook workflow.
Prospect CRM	Organises food and beverage prospect research, hypothesised needs, lead stages, priorities and follow-up actions.
Content Calendar	Plans LinkedIn and website content, approval stages, publication and performance metrics.
Project Tracker	Tracks workstreams, owners, milestones and progress for illustrative manufacturing projects.
Research Queue	Organises industry and partner research topics, findings and next steps.
Dashboard	Summarises metrics derived from workbook records for an overview of sales, marketing and project activities.


Proposed workflow
1. Research: Identify potentially relevant food and beverage businesses and document sourced findings.
2. Qualify: Distinguish hypothesised needs from confirmed client interest; select decision-makers for authorised outreach.
3. Engage: Draft personalised messaging and educational LinkedIn or website content for review.
4. Coordinate: Track marketing deliverables and manufacturing project tasks, dependencies and deadlines.
5. Measure: Update the source tabs with real activity and results so the dashboard can support weekly reviews.

How to use
1. Download Cibus Nexum.xlsx from this repository.
2. Open the file in Microsoft Excel.
3. Start with Guide, then examine Dashboard.
4. Review Prospect CRM, Content Calendar, Project Tracker, and Research Queue.
5. Replace example data with verified, approved information before operational use.
Note: GitHub displays the workbook as a downloadable file; Microsoft Excel is recommended for the full formatted dashboard and workbook experience.
